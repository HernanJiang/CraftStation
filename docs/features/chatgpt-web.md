# ChatGPT 网页输出映射（1.9.0）

在 CraftStation 聊天框输入文字，提交给已登录的 ChatGPT 网页；生成中的文字、图表、计算器、模拟器和网页小组件映射到 CraftStation 对话区。模型和组件继续由原网页运行，登录状态及 MCP Apps 的宿主连接保留在原网页中。

## 使用

1. 点击顶部的 **ChatGPT 网页**，创建新对话。
2. 在打开的内置浏览器中登录 ChatGPT，选择网页中的模型。现有浏览器登录状态可继续使用。
3. 等待本地输入框显示 **已连接**，在 CraftStation 输入并发送。
4. 回复生成时可点击本地停止按钮；打开网页可以查看原始对话、选择模型或处理网页提示。
5. 使用会话下拉框继续已有网页对话。已同步文本和网页地址保存在应用数据目录的 `chatgpt-web-sessions.json`。

## 账号中的对话与思考强度

- **创建**：点击新对话，使用已登录的账号打开 ChatGPT 新聊天。第一次发送后，沿用网页生成的正式对话地址。
- **导入并续聊**：点击导入已有对话，从网页已加载的会话列表选择，或粘贴自己的 `https://chatgpt.com/c/…` 链接。项目中的对话链接也可接入；分享链接不能继续原会话。同一链接重复导入会打开已有本地记录。列表仅包含网页当前已加载的对话，更早的对话可先在网页加载或直接粘贴链接。
- **思考强度**：点击输入框上方的思考强度按钮。选项和名称来自当前网页的原生滑杆，读取后恢复原选择；应用时再次检查实际档位名称。已登录测试账号当前提供即时、中、高、极高和 Pro，其他账号和模型以自己的网页为准。网页未开放控件时明确提示，不伪造选项。
- **删除**：删除按钮会显示会话标题、地址，以及同步删除账号原对话的确认提示。确认后核对网页会话地址和原生确认框中的标题，只提交一次删除；网页确认成功才移除本地记录并关闭对应标签。结果不明确时保留记录并提示用户检查网页。生成中不允许删除或调节思考强度。

已绑定的网页会话切换到其他对话时会停止同步并提示重新打开原对话或另行导入，避免将不同对话混入同一记录。网页登录、模型选择、套餐权限和网页工具仍由用户自己的 ChatGPT 账号决定。

当前入口标为 **实验**，支持桌面端。正文复用现有 Markdown 渲染，保留网页可读取的代码、表格、公式和链接；回复中的 iframe、图表和可视化容器作为交互卡片展示。自动识别未覆盖的网页结构，可打开同一回复下的“原网页回复”卡片。上传附件、语音以及网页的账号管理继续在原网页中操作。网页改版可能需要更新兼容逻辑。

## 小程序和组件

- 识别到的组件自动连接；其他卡片可点击“打开交互”。当前会话同时显示一个实时组件，避免多个页面区域相互争夺滚动位置。
- 在卡片内点击、拖动滑块、滚动、输入或使用方向键，操作会传回原网页中的同一个组件。输入中文可先点击组件输入框，再使用卡片下方的文字输入栏。
- “展开”在弹窗中显示同一个组件；“保存图片”保存当前 PNG 画面；“继续修改”把组件名称带入当前对话的修改草稿，用户编辑后发送。
- 本地历史保存文字、网页地址及组件引用。重新打开后连接原网页恢复交互。PNG 是当前画面的快照，交互程序没有导出为离线 HTML。
- 原网页登录失效、切换对话、控件移位或页面弹层遮挡时，拒绝旧画面的操作并提示刷新或重新连接。

[官方 Visualizations](https://learn.chatgpt.com/docs/visualizations) 的组件由网页运行。[公开 MCP Apps](https://developers.openai.com/plugins/build/chatgpt-ui) 的 iframe 消息桥接也留在原宿主中；CraftStation 不接管第三方工具授权，不把外部脚本复制到具有 Node 权限的应用渲染器中。

## 发送与恢复

- 网页输入框有草稿时，提示用户先处理草稿，避免覆盖。
- 同一次提交只点击一次发送，生成中的回复更新原消息，避免重复追加。
- 网页显示登录失效、回复加载失败或连接中断时，保留已有内容并显示原因。先打开网页处理问题，再显式重新连接；已提交的消息不会自动重发。
- 重启恢复会话地址和已同步历史，不重放未完成请求。网页长对话移除早期 DOM 时，保留已经同步且有稳定身份的消息。

## 实现边界

`ChatGptWebRuntime` 通过 `WebChatBrowser` 接口驱动内置浏览器的可见输入框和按钮，读取回复 DOM；`WebChatWidgetMirror` 通过同一个接口截取组件画面并投递有限的输入事件。渲染端经类型化 IPC 接收会话快照、组件引用和 PNG。只驱动正式的 `https://chatgpt.com` 页面。登录由网页管理，不导出 Cookie，不使用隐藏聊天接口。

这是一条独立网页对话路径，当前没有注册为 Agent Harness，也没有把网页工具、MCP、Skills 或原生 Agent Session 声称为 CraftStation 能力。Auto 与 Recipe 保持现有执行路径。
