# GPT-6.1 Sol Ultrafast（1.9.0）

模型菜单显示当前账号目录提供的速度档位。新线程默认 Standard；支持的模型可切换 Fast 或 Ultrafast，之后的回合使用新选择。

## 权限和真实生效

- 从官方模型目录更新档位，目录中已移除的选项不保留。静态目录只能显示“权限待确认”，不能证明账号已经开通。
- 对明确不支持的 ChatGPT 套餐，在提交回合前拒绝 Ultrafast。通用 `pro` 名称不足以证明 Pro $500，Enterprise/Edu 的权限仍需官方目录和运行时确认。
- 提交 Ultrafast 前再次读取当前账号的官方模型目录。未声明支持时明确拒绝，避免 CLI 省略参数后按默认档位执行。
- 对话中分别显示请求档位和服务端明确报告的实际档位。若服务端没有报告实际值，显示“实际档位未报告”；完成回复和请求参数回显都不算实际生效证据。明确降档或拒绝时显示对应状态。
- 菜单及 Ultrafast 回合提示用量规则：订阅内额度按 Standard 的 8 倍计用量，购买额度按 6 倍；API 使用独立计价与限流。

## 来源与验收边界

[2026-10-08 官方更新](https://learn.chatgpt.com/docs/changelog) 和[速度档位说明](https://learn.chatgpt.com/docs/agent-configuration/speed)说明了模型、套餐及用量边界。
