## 最终行为

- 主对话卡片直接显示完整网页，使用原生输入框、消息及小部件；下方应用对话框、整条控制栏与视图切换入口已移除。外层保留 CraftStation 卡片、同步线程标题及右上角刷新按钮。
- 普通打开侧栏时，右侧使用独立网页，左边主网页保持显示和原有输入草稿。远程网页与普通浏览器分别保持挂载，每个标签只拥有一个 WebContents；移除列表记录也不改变已有网页的宿主。
- 刷新旁新增“打开为本地对话侧边栏”：弹窗支持搜索已有本地线程，选择后正常切换项目与线程，把当前网页实例放到目标线程右侧。原生输入及草稿保留；不创建新线程、不发送消息、不移除远程记录。
- 远程 `+` 直接在主卡片打开新的 ChatGPT 网页，无创建方式选择弹窗。已有对话通过网页自己的会话列表选择，自动同步线程名称和绑定地址。
- 右上角已有对话胶囊改为刷新网页，位于顶部侧边栏按钮左侧，直接重载当前标签并显示实际加载状态，保持同一 WebContents。网页同步失败或生成状态仍可刷新；刷新期间切换线程不会被旧结果抢回。
- 默认入口优先恢复选中的绑定线程，或复用侧边已打开的会话并选中对应远程线程。每个线程保留自己的对话 ID 与标签；来源标签换绑另一会话时解除旧标签引用。重启按对话 ID 复用恢复的浏览器标签，登录失效保留地址；旧同步结果不能改回左侧选中项。
- 当前线程跟随原网页选择的会话，更新对话 ID、左上角及左侧名称。网页标题为 ChatGPT 时从当前侧栏链接读取名称，排除正文引用；仅重命名也保存。再次点击顶部入口保留当前新建页的线程并继续同步。点击左侧线程恢复各自最近保存的会话，正确页面不刷新并保留草稿；账号原对话删除仍需确认。
- 兼容映射实现保留供内部回归，不提供用户切换入口。普通 HTML 小部件识别、滑块末次移动和提交发现登录失效时的草稿保留回归均通过。
