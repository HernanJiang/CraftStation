## CraftStation v1.7.7

Real output tokens from every harness. The tok/s reading now prefers each harness's own token counters — Codex, Claude, OpenCode, Kimi, Grok, Cursor, Pi, Command Code, Muse and DeepSeek all report their real output where the CLI exposes it — and generation time is stamped where the provider emits it, so batching delays can't inflate the rate.
